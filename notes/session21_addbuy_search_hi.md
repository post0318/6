# Session 21 — H/I 추가매수(주기·비중)만 변수로 탐색

## 설정 (`backtest/addbuy_search_hi.py`, `addbuy_search_hi.csv`)

상수: 초기편입 40% / 10일 분할 / 재진입·매도 79 / 급락 31 / 급락매수 100%.
H = 매도 100%, I = 매도 50%(국면당 1회). 변수: 추가매수 주기 13종(1~126일) × 비중 14종(1~100%).
표본 5년 / 2011~2026. 두 표본의 백분위 순위 평균으로 "견고한" 최적점을 뽑았다.

목표 정의:
- 수익률 = 총수익률
- 위험관리 = 롤링 2년 최악수익률 + 롤링 2년 손실확률(순위 평균). **MDD는 전 조합 -36.4%,
  롤링 1년 최악은 전 조합 -35.3%로 동일**해 변별력이 없음(2022 하락 때 이미 만액 편입 상태).
- 밸런스 = Sharpe-like

## 결과

| 후보 | 목표 | 주기/비중 | 5년 수익률 / Sharpe / 2년최악 | 2011 수익률 / Sharpe / 2년최악 |
|---|---|---|---|---|
| H | 기준 | 21일/10% | 99.5% / 0.743 / -6.8% | 577.5% / 0.730 / -23.3% |
| H | 수익률 (견고) | 84일/1% (사실상 추가매수 없음) | 101.5% / 0.753 / -6.1% | 579.2% / 0.731 / -23.4% |
| H | 위험관리 | 14일/2% | 101.0% / 0.750 / -6.3% | 581.0% / 0.732 / -23.4% |
| H | 밸런스 | 14일/1% | 101.2% / 0.752 / -6.2% | 580.1% / 0.732 / -23.4% |
| I | 기준 | 21일/10% | 94.8% / 0.719 / -10.5% | 705.3% / 0.783 / -21.9% |
| I | 수익률 | 42일/100% | 97.7% / 0.733 / -9.6% | 745.9% / 0.798 / -22.1% |
| I | 위험관리 | 42일/50% | 97.5% / 0.732 / -9.7% | 742.6% / 0.798 / -22.1% |
| I | 밸런스 | 42일/75% | 97.6% / 0.733 / -9.6% | 745.6% / 0.798 / -22.1% |

- 표본별 수익률 1위는 서로 반대: 5년은 느린 주기(H 84일+), 2011은 2일/100%(H 702.8%, I 785.4%).
  2일/100%는 5년에서 H 88.1%, I 85.9%로 기준보다 나빠 견고하지 않다.
- I는 42일 주기가 두 표본 모두 Sharpe 1위(0.733 / 0.798). 42~63일에서 5년 성과가 평탄해 스파이크는
  아니지만, 2011에서는 42일 이후 완만히 하락(742.6% → 709.1%, 비중 50%).
- H는 주기별 성과가 들쭉날쭉(38~40일 좋고 42~55일 나쁨)해 특정 주기를 고르는 의미가 약하다.
  1~2% 소액·14일 또는 84일 이상 = "추가매수를 사실상 하지 않는 것"이 두 표본에서 기준보다 약간 낫다.
- 추가매수 변경의 효과는 Sharpe 기준 +0.01~0.02 수준. 트리거(79/31)가 노출을 결정한다는 session 20
  결론이 재확인됨. 어떤 조합도 2011 표본에서 Buy&Hold(885.4% / 0.815)를 넘지 못했다.
