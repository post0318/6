# Session 22 — 코스피 분석 두 갈래: K공포지수(국내) vs CNN FG(원본, 매매 대상만 교체)

사용자가 요청한 두 가지 별도 실험.

## 1. K공포지수(5번 프로젝트, KRX 데이터 기반) × 코스피 종합지수

데이터: 5번 프로젝트에 신규 export 라우트(`/api/macro/kr-fg-history`, 기존 대시보드
응답과 분리·무영향)를 추가해 K공포지수 전체 히스토리(1,519일, 2020-07-06~)와 코스피
종가(1,560일, 2020-05-27~)를 받아옴 → `data/kr_fg_full.json`.
스크립트: `analysis/explore_kr.py`(1차 상관관계+기존 A~I 파라미터 적용),
`backtest/trigger_reverse_search_kr.py`(코스피 전용 트리거 격자 탐색, 최근5년/전체6.2년
교차검증).

**상관관계**: FG(당일) vs 당일수익률 0.247 (CNN-나스닥의 0.56보다 뚜렷이 약함).
방향성(당일 동행, 익일 예측력 거의 없음)은 같아 1일 지연 적용은 타당.

**트리거 격자 탐색 결과**: 두 표본(최근5년 2021-09-23~, 전체 2020-07-06~) 모두에서
Buy&Hold를 안정적으로 이기는 조합을 찾지 못함.
- 매도기준을 아주 높게(85~90) 잡은 조합은 사실상 "거의 안 판다" = Buy&Hold를 흉내내는
  퇴화 해(degenerate solution)일 뿐, 신호 자체의 효과가 아님.
- 위험조정(Sharpe) 최적 조합(F구조, 매도55/급락31~33)은 최근5년에서 MDD를 -38.6%→
  -19%로 크게 줄이고 Sharpe도 0.706→0.820으로 개선하지만, 전체6.2년으로 확장하면
  Sharpe 0.780 < BH 0.835로 역전 — 좁은 표본에 맞춘 결과라는 기존 나스닥 분석의 교훈과
  동일한 패턴.
- **주의**: K공포지수 히스토리가 6.2년뿐이라 나스닥의 2011~2026(15.7년) 같은 긴 교차검증
  표본이 아직 없음 — 결론은 잠정적이고, 데이터가 쌓이면 재검토 필요.

## 2. CNN FG(원본, 미국) 신호 × 코스피200(KODEX 200 ETF, 069500.KS) 매매

"신호는 그대로 CNN, 매매 대상만 나스닥→코스피200"으로 바꾼 버전.
코스피200 지수 자체(`^KS200`)는 Yahoo Finance 데이터가 사실상 없어(1일치),
코스피200을 추종하는 KODEX 200 ETF(2011-01-03~ 데이터 존재, CNN FG 외부 보완
데이터 시작일과 일치)를 대신 사용 — 실제 ETF라 나중 실매매 검증에도 재사용 가능.
스크립트: `scripts/fetch_kospi200.py`, `analysis/explore_cnn_kospi200.py`.

| 표본 | Buy&Hold | 최고 후보 |
|---|---|---|
| 전체(2011~, 3711일) | 418.0% / Sharpe 0.595 | I: 370.9% / Sharpe 0.582 |
| 최근5년(1158일) | 193.3% / Sharpe 0.878 | H: 225.4% / **Sharpe 0.961** |

- H/I(트리거 79/31)가 A~G보다 훨씬 낫고, 최근5년에서는 H가 Sharpe로 Buy&Hold를
  근소하게 이김(0.961 vs 0.878) — 절대수익은 여전히 못 미침.
- **MDD가 모든 후보·모든 표본에서 Buy&Hold와 완전히 동일(-40.81%)**. 확인해보니 이건
  버그가 아니라 코스피200(KODEX200) 자체의 역대 최대낙폭이 2026-07-30 발생한 최근
  급락이고, 그 시점에는 모든 전략이 이미 거의 100% 투자 상태였기 때문 — 즉 CNN FG
  신호가 이번 급락은 전혀 피하지 못함.

## 결론 (잠정)

두 실험 모두 Buy&Hold를 총수익률로 안정적으로 이기는 조합은 없음. CNN FG를 코스피200에
적용한 쪽이 K공포지수를 코스피 종합지수에 적용한 쪽보다 Buy&Hold에 더 근접(특히 H/I,
위험조정 기준으로는 근소 우위)하지만, 최근 급락을 전혀 피하지 못했다는 한계가 뚜렷.
K공포지수는 표본이 짧아(6.2년) 장기 결론을 내리기엔 이름.
