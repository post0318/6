# Session 28 — 코스피 분석 두 갈래: K공포지수(국내) vs CNN FG(원본, 매매 대상만 교체)

사용자가 요청한 두 가지 별도 실험. **작업 중 발견한 실수**: 이 세션은 로컬 체크아웃이
origin/master보다 2커밋 뒤처진 상태(session 21~26의 추가매수·2022 약세장·크래시레벨·
추세필터 탐색과 candidate J 추가가 반영 안 됨)로 시작해, 처음엔 옛 A~I 파라미터로
코스피를 분석했다. 사용자 지적으로 `git fetch`+`git merge`(파일 단위 충돌 없음, 안전하게
병합)한 뒤 candidate J(추세 보험 포함)까지 반영해 재실행했다 — 아래는 재실행 결과.

## 1. K공포지수(5번 프로젝트, KRX 데이터 기반) × 코스피 종합지수

데이터: 5번 프로젝트에 신규 export 라우트(`/api/macro/kr-fg-history`, 기존 대시보드
응답과 분리·무영향)를 추가해 K공포지수 전체 히스토리(1,519일, 2020-07-06~)와 코스피
종가(1,560일, 2020-05-27~)를 받아옴 → `data/kr_fg_full.json`.
스크립트: `analysis/explore_kr.py`(상관관계 점검 + `export_dashboard_json.SIGNAL_CANDIDATES`
A~J를 그대로 적용, J의 175일선 추세 보험은 나스닥이 아니라 코스피 자신의 종가로 재계산),
`backtest/trigger_reverse_search_kr.py`(코스피 전용 트리거 격자 탐색, 최근5년/전체6.2년
교차검증 — 아직 A~I 트리거만 탐색, J 스타일 추세보험 격자는 포함 안 함).

**상관관계**: FG(당일) vs 당일수익률 0.247 (CNN-나스닥의 0.56보다 뚜렷이 약함).
방향성(당일 동행, 익일 예측력 거의 없음)은 같아 1일 지연 적용은 타당.

**A~J 전체 성과** (나스닥용 파라미터 그대로, 코스피 전용 재탐색 전):

| 표본 | Buy&Hold | 최고 후보 | candidate J |
|---|---|---|---|
| 전체(6.2년) | 215.1% / Sharpe 0.835 | I: 68.8% / Sharpe 0.514 | 33.0% / Sharpe 0.411 |
| 최근5년 | 120.4% / Sharpe 0.706 | I: 48.5% / Sharpe 0.472 | **-2.9% / Sharpe 0.035** |

**candidate J(나스닥 최종 추천)가 코스피에서는 오히려 최악이다.** 175일선 추세 보험을
코스피 자체 종가로 재계산해 적용했더니 최근5년 수익률이 마이너스(-2.9%)로 나온다 —
나스닥 가격 패턴에 맞춰 고른 추세 필터 파라미터(175일/3%버퍼/25%cap)가 코스피의
등락 리듬과 안 맞아 휩쏘(잦은 오발동)로 깎아먹는 것으로 보인다.

**트리거 격자 탐색 결과** (A~I 트리거만, J의 추세보험 격자 미포함): 두 표본(최근5년
2021-09-23~, 전체 2020-07-06~) 모두에서 Buy&Hold를 안정적으로 이기는 조합을 찾지 못함.
- 매도기준을 아주 높게(85~90) 잡은 조합은 사실상 "거의 안 판다" = Buy&Hold를 흉내내는
  퇴화 해(degenerate solution)일 뿐, 신호 자체의 효과가 아님.
- 위험조정(Sharpe) 최적 조합(F구조, 매도55/급락31~33)은 최근5년에서 MDD를 -38.6%→
  -19%로 크게 줄이고 Sharpe도 0.706→0.820으로 개선하지만, 전체6.2년으로 확장하면
  Sharpe 0.780 < BH 0.835로 역전 — 좁은 표본에 맞춘 결과라는 기존 나스닥 분석의 교훈과
  동일한 패턴.
- **주의**: K공포지수 히스토리가 6.2년뿐이라 나스닥의 2011~2026(15.7년) 같은 긴 교차검증
  표본이 아직 없음 — 결론은 잠정적이고, 데이터가 쌓이면 재검토 필요.

## 2. CNN FG(원본, 미국) 신호 × 코스피200(KODEX 200 ETF, 069500.KS) 매매

"신호는 그대로 CNN, 매매 대상만 나스닥→코스피200"으로 바꾼 버전.
코스피200 지수 자체(`^KS200`)는 Yahoo Finance 데이터가 사실상 없어(1일치),
코스피200을 추종하는 KODEX 200 ETF(2011-01-03~ 데이터 존재, CNN FG 외부 보완
데이터 시작일과 일치)를 대신 사용 — 실제 ETF라 나중 실매매 검증에도 재사용 가능.
스크립트: `scripts/fetch_kospi200.py`, `analysis/explore_cnn_kospi200.py`.

| 표본 | Buy&Hold | 최고 후보 | candidate J |
|---|---|---|---|
| 전체(2011~, 3711일) | 418.0% / Sharpe 0.595 | I: 370.9% / Sharpe 0.582 | 158.0% / Sharpe 0.431, MDD **-42.2%** |
| 최근5년(1158일) | 193.3% / Sharpe 0.878 | H: 225.4% / **Sharpe 0.961** | 143.4% / Sharpe 0.788 |

- H/I(트리거 79/31)가 A~G, J보다 훨씬 낫고, 최근5년에서는 H가 Sharpe로 Buy&Hold를
  근소하게 이김(0.961 vs 0.878) — 절대수익은 여전히 못 미침.
- **candidate J가 여기서도 H/I보다 확연히 뒤처진다.** 게다가 전체(2011~) 표본에서는
  MDD가 -42.2%로 Buy&Hold(-40.81%)보다 더 나쁘다 — 추세 보험이 지키기는커녕 더 깎아먹은
  드문 경우. 코스피200 자체 종가로 재계산한 175일선 필터가 여기서도 잘 안 맞는다.
- **MDD가 H/I를 포함한 대부분 후보·두 표본에서 Buy&Hold와 완전히 동일(-40.81%)**.
  확인해보니 이건 버그가 아니라 코스피200(KODEX200) 자체의 역대 최대낙폭이 2026-07-30
  발생한 최근 급락이고, 그 시점에는 모든 전략이 이미 거의 100% 투자 상태였기 때문 —
  즉 CNN FG 신호가 이번 급락은 전혀 피하지 못함.

## 3. 코스피 전용 추세 보험 재탐색 (`backtest/trend_filter_search_kr.py`)

candidate J의 나스닥 추세필터(175일/3%/25%)가 코스피에서 역효과였으므로, session 26과
같은 방법(이평×버퍼×cap×매수트리거 격자, 최근5년/전체 교차검증)으로 코스피 전용 값을
직접 찾았다. 기준 구조는 J와 같은 H/I+매도77(50%)+급락(전량매수), 추세 필터만 재탐색.

**K공포지수 × 코스피**: 어떤 조합도 두 표본에서 일관되게 좋지 않음 — 최근5년 최적은
Sharpe 0.344에 그치고, 전체 최적(MA100/버퍼0/cap0)은 전체에서 Sharpe 0.684로 괜찮아
보이지만 최근5년으로 보면 0.156~0.277로 무너짐. K공포지수 자체 신호가 약해서(당일
상관계수 0.247) 추세 필터를 아무리 조정해도 안정적인 개선이 안 나온다.

**CNN FG × 코스피200(KODEX200)**: 여기서는 확실히 다른 그림이 나온다.

| 표본 | Buy&Hold | 코스피 전용 추세보험(MA60/버퍼0%/cap0%/급락30) |
|---|---|---|
| 최근5년 | 193.3% / Sharpe 0.878 / MDD -40.8% | **240.0% / Sharpe 1.266 / MDD -21.2%** |
| 전체(2011~) | 418.0% / Sharpe 0.595 / MDD -40.8% | 224.5% / Sharpe 0.627 / MDD -22.0% |

최근5년 기준으로 찾은 이 설정이 전체(2011~) 표본에서도 Sharpe·MDD 모두 Buy&Hold를
이긴다(절대수익은 전체 표본에서 못 미침 — 15년 중 상당수를 추세 이탈로 현금 보유했을
것). 반대 방향(전체 최적: MA100/버퍼0/cap0/급락31)도 최근5년에서 Sharpe 0.963으로
Buy&Hold(0.878)를 이기고 MDD도 -31.2%로 크게 개선 — 양방향 교차검증을 통과한 몇 안
되는 진짜 개선. **candidate J와 달리 버퍼=0%·cap=0%(부분 축소가 아니라 완전 이탈)가
핵심**이라, "이평선 아래로 내려가면 전량 현금화, 위로 올라오면 즉시 복귀"라는 단순한
규칙이 코스피200에서는 나스닥의 175일/3%버퍼/25%cap보다 훨씬 잘 맞는다.

이 설정은 아직 대시보드 후보로 등록하지 않았다(export_dashboard_json.py는 나스닥
전용이라 손대기 전에 확인 필요) — 다음 단계 후보.

## 결론 (잠정)

두 실험 모두 Buy&Hold를 총수익률로 안정적으로 이기는 조합은 없음. CNN FG를 코스피200에
적용한 쪽이 K공포지수를 코스피 종합지수에 적용한 쪽보다 Buy&Hold에 더 근접(특히 H/I,
위험조정 기준으로는 근소 우위)하지만, 최근 급락을 전혀 피하지 못했다는 한계가 뚜렷.
**나스닥에서 최종 추천이었던 candidate J의 175일선 추세 보험은 두 코스피 실험 모두에서
역효과 — 파라미터가 시장(나스닥) 특화라 그대로 못 옮긴다는 뜻이며, 코스피 전용 추세
보험 파라미터를 다시 찾아야 할 수도 있음.** K공포지수는 표본이 짧아(6.2년) 장기 결론을
내리기엔 이름.
