# Session 29 — 추세 보험 해제 시 즉시 복원 vs 정기매수로만 채우기 (`backtest/restore_mode_check.py`)

`scenario_2022.simulate_overlay`에 `restore` 옵션 추가(기본 True = 기존과 동일). 기준: 후보 J.

| 해제 시 | 2011 수익률 / Sharpe / MDD | 5년 수익률 / Sharpe / MDD |
|---|---|---|
| 즉시 복원 (현재 J) | **587.1% / 0.944** / -19.4% | **101.8% / 1.053** / -17.0% |
| 복원 없음, 정기 21일/10% | 399.6% / 0.849 / -18.7% | 82.1% / 0.939 / -17.0% |
| 복원 없음, 정기 21일/20% | 425.1% / 0.859 / -18.9% | 83.3% / 0.941 / -17.0% |
| 복원 없음, 정기 10일/10% | 431.2% / 0.855 / -19.2% | 84.8% / 0.948 / -17.0% |
| 복원 없음, 정기 5일/10% | 477.7% / 0.858 / -19.6% | 87.9% / 0.949 / -17.3% |

- 복원 없이 21일/10%로 채우면 25% → 100%까지 약 8개월(21일 × 8회). 이평선 회복 직후의 반등장을 대부분 놓쳐
  2011 수익률 -187%p, Sharpe -0.10. MDD·2022 하락폭은 거의 같아 위험 감소 효과가 없다.
- 정기매수를 빠르게 해도(5일/10%) 즉시 복원에 못 미친다. 해제 신호(175일선 회복) 자체가 재진입 타이밍으로 유효.
- 결론: 즉시 복원 유지.
