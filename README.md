# Project 6 — Fear & Greed 역발상 투자 리서치

CNN Fear & Greed Index가 인덱스(S&P 500 등) 투자의 역발상(contrarian) 매매 신호로 쓸모가 있는지 실증적으로 검증하는 리서치 프로젝트.

## 가설

- **공포(Fear) 구간에서의 반등**: 지수가 저점(극단적 공포)에서 반등하기 시작하면 시장 여건이 개선되고 있다는 신호이며, 이는 매수 기회일 수 있다.
- **탐욕(Greed) 구간의 지속**: 지수가 높은 탐욕 수준을 일정 기간 이상 지속하면, 어느 시점에 선제적으로 비중을 줄이는 것이 수익률 방어에 도움이 될 수 있다.
- 단일 최적 시점은 없다고 전제하고, 실증분석·상관분석·회귀분석을 거쳐 여러 요인을 반영하는 시뮬레이터로 근사적인 최적 진입/청산 규칙을 탐색한다.

## 진행 방식

- 매주 진행하되 **주간 모델 사용량의 30%를 넘지 않는 선**에서 단계적으로 진행한다 (한 번에 몰아서 끝내지 않음).
- 4번 프로젝트와는 무관한 독립 프로젝트.

## 단계 (Phases)

1. **데이터 수집** — CNN Fear & Greed Index 과거 데이터 + S&P 500(또는 벤치마크 지수) 가격 데이터 확보 (`data/`)
2. **탐색적 분석** — 지수 구간(extreme fear/fear/neutral/greed/extreme greed)별 이후 N일/N주 수익률 분포, 상관관계, lag 분석 (`analysis/`)
3. **회귀분석** — 지수 수준·변화율(반등 여부) 등을 설명변수로 미래 수익률을 회귀 (`analysis/`)
4. **백테스트 시뮬레이터** — 규칙 기반(또는 여러 요인 가중) 진입/청산 전략을 과거 데이터에 백테스트, buy-and-hold 대비 성과 비교 (`backtest/`)
5. **검증 및 정리** — out-of-sample 검증, 결과 요약

## 현재 상태

- Phase 0: 프로젝트 골격 및 계획 수립 완료.
- 다음 세션: Phase 1 데이터 수집 스크립트 작성.
